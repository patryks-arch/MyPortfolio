## Project Overview
Analyzed product margins and shipping cost bottlenecks for over 100,000 orders from the Olist e-commerce dataset.

## Key Features & Deliverables
* **ETL & Relational Database:** Designed and populated a PostgreSQL database structure.
* **Advanced Analytics:** Wrote complex SQL queries featuring CTEs, Window Functions, and multi-table JOINs to aggregate sales performance.
* **BI Dashboard:** Developed an interactive Power BI dashboard with direct database connectivity (DirectQuery).

## Tech Stack
* PostgreSQL, SQL
* Power BI (DAX, PowerQuery)
* Python (Pandas)
