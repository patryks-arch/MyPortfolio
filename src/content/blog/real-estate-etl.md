## Project Overview
An automated pipeline collecting real estate listings to detect undervalued property offers and track price fluctuations by district.

## Key Features & Deliverables
* **Web Scraping:** Automated extraction script using Python (`BeautifulSoup`) and Regex for data cleaning.
* **Database Pipeline:** Structured data storage in PostgreSQL with error handling and query optimization.
* **Market Analytics:** Power BI dashboard spotlighting district price trends and outlier detection.

## Tech Stack
* Python (BeautifulSoup, Regex, Pandas)
* PostgreSQL
* Power BI
